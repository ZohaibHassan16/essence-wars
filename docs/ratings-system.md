# Unified Ratings System

*Documentation for the Essence Wars ELO rating system*

**Last Updated:** 2026-02-01

---

## Overview

The Essence Wars ratings system provides a unified view of competitive strength across both **deck archetypes** (from Rust arena play) and **ML agents** (from Python benchmarks). Both use ELO ratings with K=32 for consistent comparison.

## Architecture

```
essence_wars/ratings/
├── base.py              # Base classes, ELO utilities
├── deck_ratings.py      # Deck ratings from arena
├── agent_ratings.py     # Agent ratings from benchmarks
└── unified.py           # Combined leaderboard
```

### Rating Categories

```python
class RatingCategory(Enum):
    DECK = "deck"    # Commander decks (Rust arena)
    AGENT = "agent"  # ML agents (Python benchmarks)
```

## Deck Ratings

### Overview

Deck ratings are computed by the Rust `arena` binary through round-robin tournaments. Ratings are stored in `data/ratings/deck_elo.json`.

### Data Format

**`data/ratings/deck_elo.json`:**
```json
{
  "broodmother_pack": {
    "faction": "Symbiote",
    "commander_name": "Broodmother's Swarm",
    "rating": 1615.3,
    "games_played": 450,
    "wins": 276,
    "losses": 174,
    "history": [
      {"rating": 1500.0, "timestamp": "2026-01-15T10:00:00Z"},
      {"rating": 1532.1, "timestamp": "2026-01-16T14:30:00Z"},
      ...
    ]
  },
  ...
}
```

### Python API

```python
from essence_wars.ratings import DeckRatings

# Load ratings
ratings = DeckRatings.load()

# Get ranked decks
for deck in ratings.get_ranked()[:5]:
    print(f"{deck.display_name}: {deck.rating:.0f} ELO")

# Predict matchup
prob = ratings.predict_matchup("broodmother_pack", "celestial_vanguard")
print(f"Win probability: {prob:.1%}")

# Get deck info
deck = ratings.get("broodmother_pack")
print(f"Win rate: {deck.win_rate:.1%}")
print(f"Games: {deck.games_played}")
```

### Generating Deck Ratings

Deck ratings are generated by running the Rust arena:

```bash
# Run validation (round-robin tournament)
cargo run --release --bin validate -- --games 100 --output results.json

# Arena automatically updates data/ratings/deck_elo.json
```

**Tournament Structure:**
- 12 commander decks (4 per faction)
- 66 unique matchups (12 choose 2)
- Each matchup played 2x (P1/P2 swap)
- 132 total matchups × games per matchup

## Agent Ratings

### Overview

Agent ratings track ML model performance against baselines. Ratings are stored in `data/ratings/agent_elo.json` and updated through Python benchmarks.

### Data Format

**`data/ratings/agent_elo.json`:**
```json
{
  "bc_mcts_10k_best": {
    "agent_type": "behavioral_cloning",
    "model_path": "models/bc_mcts_10k_best.pt",
    "rating": 1654.2,
    "games_played": 320,
    "wins": 203,
    "losses": 117,
    "history": [
      {"rating": 1500.0, "timestamp": "2026-01-20T09:00:00Z"},
      {"rating": 1548.7, "timestamp": "2026-01-20T11:45:00Z"},
      ...
    ]
  },
  ...
}
```

### Python API

```python
from essence_wars.ratings import AgentRatings

# Load ratings
ratings = AgentRatings.load()

# Track a game result
ratings.update(
    agent_name="my_ppo_agent",
    opponent_name="greedy",
    winner=0  # 0 = agent won, 1 = opponent won
)

# Save updated ratings
ratings.save()

# Get agent stats
agent = ratings.get("my_ppo_agent")
print(f"Rating: {agent.rating:.0f}")
print(f"Win rate: {agent.win_rate:.1%}")

# Get ranked agents
for agent in ratings.get_ranked()[:10]:
    print(f"{agent.name}: {agent.rating:.0f} ({agent.agent_type})")
```

### Generating Agent Ratings

Agent ratings are updated through benchmarking:

```bash
# Benchmark with ELO update
essence-wars benchmark \
  --checkpoint models/my_model.pt \
  --opponents random,greedy,mcts-50 \
  --games 100 \
  --update-elo

# Or during training
essence-wars train ppo \
  --tag my_experiment \
  --auto-callbacks \
  --update-elo
```

## Unified Leaderboard

### Overview

The unified leaderboard combines deck and agent ratings into a single view for cross-category comparison.

### Python API

```python
from essence_wars.ratings import UnifiedRatings

# Load all ratings
ratings = UnifiedRatings.load()

# Get combined leaderboard
for entry in ratings.get_leaderboard(limit=10):
    print(f"{entry.rank}. {entry.display_name}: {entry.rating:.0f} ({entry.category.value})")

# Filter by category
agents_only = ratings.get_leaderboard(category="agent", limit=5)
decks_only = ratings.get_leaderboard(category="deck", limit=5)

# Get summary statistics
summary = ratings.get_summary()
print(f"Total decks: {summary['deck_count']}")
print(f"Total agents: {summary['agent_count']}")
print(f"Avg deck rating: {summary['avg_deck_rating']:.0f}")
print(f"Avg agent rating: {summary['avg_agent_rating']:.0f}")

# Format as table
print(ratings.format_leaderboard(limit=20))
```

### CLI Usage

```bash
# Display leaderboard in terminal
essence-wars report leaderboard

# Export to HTML
essence-wars report leaderboard --format html --output leaderboard.html

# Show only agents
essence-wars report leaderboard --category agent --limit 10

# Export to JSON
essence-wars report leaderboard --format json --output ratings.json
```

## ELO Calculation

### Base Formula

```python
def expected_score(rating_a: float, rating_b: float) -> float:
    """Calculate expected score for player A vs B."""
    return 1.0 / (1.0 + 10 ** ((rating_b - rating_a) / 400))

def calculate_rating_change(
    player_rating: float,
    opponent_rating: float,
    score: float,  # 1.0 = win, 0.0 = loss
    k: float = 32.0
) -> float:
    """Calculate ELO rating change."""
    expected = expected_score(player_rating, opponent_rating)
    return k * (score - expected)
```

### Parameters

| Parameter | Value | Notes |
|-----------|-------|-------|
| **K-factor** | 32 | Standard for established ratings |
| **Starting Rating** | 1500 | Initial rating for new entries |
| **Rating Floor** | None | Ratings can go below 1500 |

### Interpretation

| Rating Difference | Win Probability | Interpretation |
|-------------------|-----------------|----------------|
| 0 | 50% | Even match |
| +100 | 64% | Slight advantage |
| +200 | 76% | Moderate advantage |
| +400 | 91% | Strong advantage |
| +600 | 97% | Overwhelming advantage |

**Example:**
```python
from essence_wars.ratings import expected_score

# 1650 vs 1500 matchup
prob = expected_score(1650, 1500)
print(f"Win probability: {prob:.1%}")  # 69.6%
```

## Rating History

### Tracking History

Both deck and agent ratings maintain a history of rating changes:

```python
from essence_wars.ratings import DeckRatings

ratings = DeckRatings.load()
deck = ratings.get("broodmother_pack")

# Get rating history
for entry in deck.history[-5:]:
    print(f"{entry['timestamp']}: {entry['rating']:.0f}")
```

### Visualization

Rating history can be visualized in HTML reports:

```bash
# Generate report with ELO tab
essence-wars report generate --tabs elo --open
```

The ELO tab includes:
- **Rating History Chart** - Line plot of top competitors over time
- **Current Rankings Table** - Sortable table with all entries
- **Win Rate Comparison** - Bar chart of win rates
- **Rating Distribution** - Histogram of rating spread

## Integration with Reports

### HTML Reports

The unified ratings system integrates with HTML report generation:

```bash
# Generate report with ELO tab
essence-wars report generate --run-id latest --tabs overview,elo --open
```

**ELO Tab Features:**
- Combined deck/agent leaderboard
- Rating history charts
- Win rate analysis
- Category badges (DECK/AGENT)
- Sortable tables

### Programmatic Access

```python
from essence_wars.analysis.report import ReportGenerator
from essence_wars.ratings import UnifiedRatings

# Generate report with ratings data
generator = ReportGenerator()
ratings = UnifiedRatings.load()

report_path = generator.generate_validation_report(
    run_id="latest",
    tabs=["overview", "elo"],
    ratings=ratings,  # Pass ratings for ELO tab
)
```

## Best Practices

### 1. Update ELO After Benchmarking

Always update ratings when benchmarking new models:

```bash
essence-wars benchmark \
  --checkpoint new_model.pt \
  --update-elo  # Important!
```

### 2. Run Sufficient Games

For stable ratings, run at least 50-100 games per opponent:

```bash
essence-wars benchmark \
  --checkpoint model.pt \
  --games 100  # Better than 10
  --update-elo
```

### 3. Benchmark Against Multiple Opponents

Test against a variety of baselines for accurate ratings:

```bash
essence-wars benchmark \
  --checkpoint model.pt \
  --opponents random,greedy,mcts-25,mcts-50,mcts-100 \
  --update-elo
```

### 4. Track Rating Changes

Monitor rating changes over training iterations:

```bash
# After each training iteration
essence-wars benchmark \
  --checkpoint models/ppo_iter{i}.pt \
  --update-elo

# View leaderboard
essence-wars report leaderboard
```

### 5. Use Descriptive Agent Names

Name agents descriptively for leaderboard clarity:

```python
# Good
ratings.update("ppo_300k_lr3e4_v1", "greedy", winner=0)

# Bad
ratings.update("model1", "greedy", winner=0)
```
