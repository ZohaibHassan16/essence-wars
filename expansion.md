# Expansion Roadmap

Discuss the following points:

1. Add scripting for custom keywords and effects
2. Expand Keyword Set to use it
3. add scripting to support custom cards
4. plan expansion sets

Goal: Each Expansion Set should be able to introduce a new keyword (one per faction), without rendering previous expansions or sets obsolote, avoiding power creep (like in MTG). Only the basic `New Horizons` Edition must be 100% compatible with the python gym, no breaking changes. 

Random, Greedy, MCTS and Alpha-Beta Bots should be able to work with new expansions (with tuning for each addition)

Each Expansion set should get one new Commander and one new Set per Faction, with the needed cards added to each faction. Neutral does not get a commmander or deck, but also new cards.
