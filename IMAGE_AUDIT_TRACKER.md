## Verification Criteria

For each card, agents verify:

1. **Identity Match**: Does the image subject match the card name?
   - e.g., "Siege Marshal Vex" should show a military commander, not an artificer

2. **Type Match**: Does the image match the card type?
   - Creatures should show beings/entities
   - Spells should show magical effects/actions
   - Supports should show structures/objects/auras

3. **Faction Aesthetic**: Does the image match faction style?
   - Argentum: Gold/brass, mechanical, Art Deco/steampunk
   - Symbiote: Purple/green, organic, bioluminescent
   - Obsidion: Crimson/black, gothic, shadowy
   - Neutral: Browns/grays, practical, wasteland

4. **Prompt Alignment**: Does the image match the generation prompt?
   - Key visual elements present
   - Correct gender/form if specified
   - Correct equipment/features
