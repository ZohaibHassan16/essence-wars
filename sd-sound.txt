Since you are comfortable with local LLMs and `stable-diffusion.cpp`, the best path forward is using **AudioCraft** by Meta. It includes two powerful models:

Below is a design for an **Audio Generation Workflow** compatible with Claude Code. This setup creates a Python "bridge" that allows Claude Code to generate audio files via CLI commands, exactly like your image workflow.

### 🎵 Essence Wars Audio Generation Guide

**Concept:** Create a unified Python script (`generate_audio.py`) that acts as your audio engine. Claude Code can then call this script to batch-generate assets.

---

### 1. The Tooling: AudioCraft

Unlike images where C++ ports (`stable-diffusion.cpp`) are standard, audio is currently best served via **Python** and **PyTorch**.

**Prerequisites:**

* NVIDIA GPU (if possible) or Mac M-series (MPS). CPU works but is slower.
* Python 3.9+
* `ffmpeg` installed on your system.

#### Setup Command (Run this once):

```bash
# Create a dedicated environment
python3 -m venv ~/ai-audio-env
source ~/ai-audio-env/bin/activate

# Install AudioCraft and dependencies
pip install 'torch>=2.0' extra-index-url https://download.pytorch.org/whl/cu118
pip install git+https://github.com/facebookresearch/audiocraft.git
pip install ffmpeg-python

```

### 2. The Bridge Script

Save this file as `~/ai-cardgame/scripts/generate_audio.py`. This is the tool Claude Code will use.

```python
import argparse
import torchaudio
from audiocraft.models import MusicGen, AudioGen
from audiocraft.data.audio import audio_write
import os
import torch

# Configuration
MODEL_CACHE_DIR = os.path.expanduser("~/.ai-assets/models/audio/")
OUTPUT_DIR = os.path.expanduser("~/.ai-assets/output/audio/")

def setup_model(model_type, size):
    """Load the appropriate model (cached locally)."""
    device = 'cuda' if torch.cuda.is_available() else 'cpu'
    if model_type == 'music':
        # Options: small, medium, large, melody
        return MusicGen.get_pretrained(f'facebook/musicgen-{size}', device=device)
    elif model_type == 'sfx':
        # Options: medium
        return AudioGen.get_pretrained(f'facebook/audiogen-{size}', device=device)

def generate(args):
    print(f"🎵 Initializing {args.type} model ({args.size})...")
    model = setup_model(args.type, args.size)
    
    # Configure generation params
    model.set_generation_params(
        duration=args.duration,
        temperature=1.0, # Higher = more creative/random
        cfg_coef=3.0     # Adherence to prompt
    )
    
    print(f"🌊 Generating: '{args.prompt}'")
    
    # Generate audio tensor
    wav = model.generate([args.prompt]) 
    
    # Save file
    filename = args.output if args.output else args.prompt.replace(" ", "_")[:20]
    output_path = os.path.join(OUTPUT_DIR, filename)
    
    # AudioCraft handles saving with sample rate automatically
    audio_write(
        output_path, 
        wav[0].cpu(), 
        model.sample_rate, 
        strategy="loudness", 
        loudness_headroom_db=16
    )
    print(f"✅ Saved to: {output_path}.wav")

if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="Essence Wars Audio Generator")
    parser.add_argument("prompt", type=str, help="Text description of the audio")
    parser.add_argument("--type", choices=['music', 'sfx'], required=True, help="MusicGen or AudioGen")
    parser.add_argument("--duration", type=int, default=5, help="Duration in seconds")
    parser.add_argument("--size", type=str, default="medium", help="Model size (small/medium/large)")
    parser.add_argument("-o", "--output", type=str, help="Output filename (without extension)")
    
    args = parser.parse_args()
    
    # Ensure output directory exists
    os.makedirs(OUTPUT_DIR, exist_ok=True)
    
    generate(args)

```

### 6. A Note on "Looping"

Generative audio (MusicGen) does not inherently create perfectly seamless loops.

* **Workaround:** Generate 30-60 seconds of music. In your game code (`Howler.js`), use a cross-fade when the track repeats (fade out the last 2s while fading in the start). It works perfectly for ambient tracks.
